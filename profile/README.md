# HistoriaMC Development

Welcome to the official development organization for **HistoriaMC**, a modded Minecraft civilization server focused on history, nation-building, diplomacy, warfare, and technological progression.

This organization hosts the source code and development resources for HistoriaMC's custom plugins, mods, and supporting infrastructure.

### Contributing
Development is managed by the HistoriaMC team. Most repositories are private unless otherwise specified.

**Website:** [historiamc.com](https://historiamc.com)
